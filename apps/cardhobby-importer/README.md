# 卡淘一键导入扩展

扩展只读取用户已经登录并主动打开的卡淘“我买到的”页面，不读取、保存或传输卡淘密码和 Cookie。

## 本地安装

1. 确认 Card Platform API 运行在 `http://127.0.0.1:8000`。
2. Chrome 打开 `chrome://extensions` 并启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 登录卡淘，打开 `https://www.cardhobby.com.cn/order/myorders?status=0`。
5. 保持 Card Platform 页面打开，扩展会自动读取本地收藏者 UUID；点击扩展图标，
   扫描并核对导入预览。

首版扫描当前订单页。分页订单需要逐页打开后分别导入；商品 ID 幂等约束会跳过重复项。

## 购买成本证据（0.2.0）

扩展新增“导出成本订单证据”，支持 `cardhobby.com.cn` 和 `www` 的大小写订单路径。
在页面弹出的面板设置最多 1–20 页，可取消，顺序读取分页与订单详情。
导出的 JSON 只含订单/商品与金额字段，不含账户凭据和收货地址；它仍是私人购买记录，请妥善保管。
在 Card Platform 的“批量识别成本 → 同步卡淘订单”选择文件，复用当前平台登录身份完成幂等同步。
完整规则、测试与当前真实页面验收边界见 [购入成本说明](../../docs/cardhobby-purchase-cost.md)。

## 自动关键字搜索（0.3.0）

在 Chrome 一次性安装 / 更新此扩展，刷新卡库并保持卡淘已登录。
卡库“更多 → 获取成本”会直接调用订单页的 `searchTxt` 搜索接口，
读取完整订单和实付金额，匹配后填入购入成本，不用导出或上传文件。
支持单卡与有断点进度的批量搜索；关键词由卡牌信息自动提取，无需填写。
只有识别出多件同款购买记录时才在卡库里选择对应订单，其余显示自动处理结果。

新增后台消息桥和本机卡库内容脚本；域名权限仍限卡淘与本机卡库。
凭据保留在卡淘标签页，仅将结构化订单字段回传本机卡库，不接收任意脚本 / URL。
搜索范围为 2000 年至当年年底；每卡最多 3 个关键字、10 页 / 100 单。
首次启用后需要刷新已经打开的卡库页面，已打开的卡淘页面会按需加载新搜索脚本。
