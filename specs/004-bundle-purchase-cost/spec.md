# 打包购入成本均摊

用户授权：修复 ID 609 及后续同类购买记录；两张共55元，每张商品成本27.50元。

沿用成本服务，新增包内位置明确的独立订单件。商品价及已分配给整包的运费分别按张数均分，分币余数按包内位置分配，金额守恒。数量必须由完整商品图片核对，不把卖家括号编号当张数。图片确认目标属于包内哪一张；位置按从上到下、同排从左到右，正反面不重复计数。无法确认、重复同款位置不明确、证据变更则不自动入账。原始订单快照保持不变。

保留订单占用、账户隔离、手工成本保护及刷新审计。补充 DC 中文角色别名供搜索和匹配使用；原有单卡规则不放松。当前609可用已人工查看的原图及订单图确认其对应左侧位置，另一位置经真实配对图确认属于608，亦录入27.50元；两卡运费分别0.62及0.61元。

用户追加范围：包含 ID 615，批量诊断全部缺失购入成本的库存并集中修复共性问题。保留逐卡分类和处理结果；有真实订单且唯一核验通过才录入，疑似、已占用、订单不完整及确无缓存候选不可硬填。


自动图片证据必须同时通过明确卡框、局部特征几何定位、裁切后独立同款和平行复核。重复/显著重叠卡框及乱序位置拒绝；包内布局和商品图摘要持久化，后续观察不能重映射位置。已入账子件不因订单证据更新而释放整包占用。模型口头断言不能独立作为分摊依据。

共性召回修复复用已有球员中英文别名，去除姓名重音符号，并将多球员姓名拆为独立主体召回；单主体命中不满足多人卡身份确认。保持原有单卡身份冲突门槛。
