# T3 客户端配对核对

- 共享契约新增可选 `pair_validation`，沿用现有任务状态；明确单面录入不增加双面门禁。
- 手机任务页和网页照片任务、扫描草稿/双图识别均显示当前双图与配对证据。unknown 必须独立勾选确认，提交服务器绑定的两面哈希；换图使旧勾选失效。conflict 禁止确认并提示重拍/重选，手机提供直接返回录卡入口。
- 网页双图识别替换为持久化 capture job；保留上传幂等键，轮询任务并下载服务器当前图后才显示审核结果。超时/失败任务仍可从照片任务查看。
- 网页扫描草稿通过 capture confirm 原子入库，保留源任务证据；不再 createItem + upload + delete 绕过服务器。无持久化任务的双面草稿无法走普通创建路径。
- 新批次 API 参数和共享 flatbed identity 字段按主任务接口协调追加；低质量、普通低识别置信度仍是提示。
