# 首版安全收尾（2026-10-30）

范围：只在隔离工作树修复会话授权、准备可兼容的 API 源码回退基线、验证真实会话和历史负载。不部署、不构建镜像、不生产写入、不新增 schema/凭据/访问配置。

1. RED：已有 auth_session/current_user，隔离 PG 创建测试用户/会话；证明 viewer 冒充 publisher/admin、bootstrap 代授角色以及省略 actor 的合法发布问题。
2. GREEN：管理 router 保存经 require_admin 校验的会话身份；所有 `_actor` 调用、bootstrap、revalue 审计使用该身份。兼容头仅允许等于会话用户。数据库脚本继续直接调用仓储，不新增服务鉴权。
3. 兼容基线：以实际上线 API digest 为父镜像，仅六个管理相关 Python 文件做源代码 overlay，保留其余生产模块。网页回退可单独回到目前 partialintake2，API 保留此兼容内核；API 故障采用该已验证兼容源码前滚修复/重建，不回到不识别 atlas_corrections 的旧 119b 镜像。不把“停发布”当安全条件。
4. 隔离验证：创建→审核→发布，重启为兼容源码候选（模拟网页回退后 legacy 客户端），再次发布/自动发布并回读，覆盖纠错链和未发布提案不丢失。另跑实际 auth 角色矩阵和合成高历史负载。全部在临时库。
5. 对齐：只读抓取实际 API 文件与 web 镜像/BUILD_ID。找到该 BUILD_ID 对应冻结网页源码，仅应用管理文件/append-only helper，不整体使用旧工作树。记录不相关源文件完全保持。
6. 相关后端/网页/类型/构建回归；独立安全复核；交付最低放行条件和未执行的目标环境检查。镜像构建、目标环境测试部署与正式切换需另行批准。
