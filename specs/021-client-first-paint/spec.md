# Feature Specification: 手机与网页首屏优先加载

Created: 2026-10-17
Status: Ready
Input: 优化初始化加载逻辑，手机版网页版都是。

## User Scenarios & Testing
### US1 首批卡片独立显示（P1）
登录用户打开卡库，默认时间排序仅计算本页卡片；汇总与纠错慢或失败不影响浏览、翻页和查看详情。手机与网页共用分页参数，保留移动端已实现的快速路径。
验收：延迟全库汇总时首批卡片仍出现；首批请求不带include_summary并使用membership；翻页复用快照；切换金额排序仍由服务端按全库值排序。
### US2 非首屏功能按需加载（P2）
网页只有打开录卡、扫描或成本面板才加载对应组件；交互、关闭、提交行为与原来一致。加载过程有明确提示。
验收：生产构建首屏不包含延迟功能模块，点击入口后能操作，失败时卡库仍可浏览。

## Requirements
FR-001 两端默认时间排序使用成员/顺序快照，只投影当前页最多page_size张卡，展示值按页读取。
FR-002 网页列表请求不合并全库汇总；列表成功返回后才启动独立汇总和纠错统计，统计错误可重试；过滤/排序/翻页不重复计算统计。
FR-003 保留快照过期恢复、搜索全库语义、金额全库排序、刷新更新值、会话过期清理。
FR-004 网页非首屏面板按需加载，保留原功能和可见加载提示。
FR-005 不修改真实卡库；保留现有未提交改动；仅一份规格计划任务。

## Edge Cases
汇总一直等待或失败、列表失败、旧请求晚到、登出后统计返回、快照失效、新卡插入或删除、金额空值、旧客户端full快照。

## Key Entities
分页请求、成员快照、当前页卡片、账户汇总、延迟组件。

## Assumptions
不改变登录鉴权顺序；手机无全库汇总页，保持当前分页/切换状态。此次为本地实现验证，不包含生产发布或iPhone安装。

## Success Criteria
SC-001 测试证明汇总挂起时仍可查看和翻页，首批列表请求不触发全库展示计算。
SC-002 两端默认分页参数与快照恢复测试通过，金额排序回归通过。
SC-003 生产浏览器能打开延迟面板；构建统计记录首屏资源变化，未实测不声称线上提速比例。
