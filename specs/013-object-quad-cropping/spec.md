# 逐张卡片四角裁切

用户于 2026-10-11 授权采用逐张物体定位、轮廓或分割确定四角、透视拉正、完整性检查的既定设计。现有裁切链路的定向改造，保留接口与原图；网格只能提供疑似位置和漏检提示。

## 用户故事
- P1：倾斜卡、位置不齐或紧贴卡套的整版扫描仍得到一张卡一个四边形，拉正后不缺角、不含邻卡。
- P1：不确定的轮廓保留人工四角校正入口和明确复核提示，不能用容量格冒充确定实体边界。
- P2：完整性检查按独立定位出的实体四边形保护卡片；水平外接框的背景不应导致正确旋转裁切被拒绝。

## 验收
1. 最新科比背面四卡原图右上倾斜框跟随卡边，左侧框不穿过相邻卡面；实际输出验证完整角点覆盖 >=98%、邻卡混入 <=1%。
2. 前一轮科比正面四卡无空白第五张；七张乔丹背面无漏项。保留倾斜、浅色、卡套紧贴的真实回归。
3. 原图、旧 revision、鉴权和人工修改保留；检测/精修/质检记录可追溯。
4. 网格提案无法定位实体边界时返回待复核结果，不以网格坐标自动裁切。
5. 完整性与分割测试覆盖：正确旋转框、内画面缩框、缺角、邻卡混入、来源边缘截断。

## 范围
使用现有 OpenCV/SAM 依赖，不训练或声称通用 YOLO 能识别本项目卡片；不修改身份识别、估值或提交入库行为。
