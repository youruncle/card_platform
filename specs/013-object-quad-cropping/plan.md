# 实施计划

## 背景与约束
Python/FastAPI/OpenCV/SAM 现有整版检测与 store_sheet 透视输出；前端已经支持 polygon 与人工四角，无需重复 UI。原有 detect_layout 产生搜索提案，实体四角层在 ML 之前消除轴对齐外包络与真实卡片的歧义。检测失败不捏造角点。

## 实现
1. 独立四角定位模块：当前像素、多档轮廓/边缘；物体候选有一致性、形状、邻卡排除与来源边缘证据。优先完整实体而非局部画面。保持任意方向四角进入既有透视裁切。
2. 将实体定位结果接入 store_sheet；网格遗留提案只作为搜索 ROI。已知实体四角传给 SAM 及 object_integrity 作保护对象。
3. 审计真实四边形覆盖和相邻实体占用；不放宽原有 grading label 与完整实体保护规则。
4. 固定 SHA 的真实原图、合成边界测试与全量历史回放；真实 SAM 输出和透视结果目视核对。满足验证后加载本机新版。

## Constitution Check
增量实现，保留用户未提交修改；一份规格/计划/任务，不复制另一套。只处理当前任务的派生裁图，不修改卡库与市场依据。验证时发现该批次已提交；其对照结果独立保存，不重写已提交 revision。缺失样本及未验证行为如实报告。

## 工具评估
OpenCV minAreaRect/boxPoints 与 getPerspectiveTransform/warpPerspective 已可用；SAM2 已在本机部署。Ultralytics OBB 是可选后续候选提供者，需私有扫描标注及独立评估，当前不引入训练和新运行依赖。

## 2026-10-14 实施补充
目标：履行既定逐物体/完整性方案，修复错误斜框可自证成功的系统缺陷。仍使用OpenCV/SAM2，不更改提交/身份/估值接口。
1. `flatbed_object_references.py` 提供当前原图完整对象参考，来自原始多路线实例及全局结构/前景/混合评级卡证据；独立保存到LayoutHypothesis，拒绝多卡合并，单独回归内部文字框与倾斜对象。
2. `flatbed_object_content.py` 保存独立对象内的结构/可见内容像素及分区，计算任意四角保留比例。测试真实标签+卡面、背景面积不计入、反光内部斜线、浅色黑白背面、倾斜与缺角。
3. `flatbed_object_quads.py` 使用独立参考扩展搜索并以内容保留约束候选，删除按bbox跨度提升斜框的启发式。保护评级标签不取水平背景面积为条件。
4. `flatbed_object_quality.py` / `flatbed_service.py` / 回放脚本使用同一独立参考校验最终SAM。已验证四角可替代错误SAM；仍失败者保留可编辑错误状态，不跑自动裁图/OCR。
5. 同一固定原图集实跑SAM、人工内容覆盖和实际透视图验证；补齐历史错误裁图的gold，记录新/旧false-usable及待校正数量。部署后只重处理仍未提交、无新捕获批次。
6. 普通卡面采用绝对色差、二维结构张量、全局及局部灰度对比区分印刷纹理和壳线；评级标签仍保留严格边缘证据。新增 `flatbed_observed_perimeter.py` 按实际四边像素保护有多路局部轮廓支持的原四角，不使用水平背景面积。内容审计固定点剔除同轮不能输出的邻卡证据。
