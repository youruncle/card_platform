# Feature Specification: NBA 新闻风险提示
Created: 2026-09-28
Status: Implementation

## User Scenarios & Testing
### P1 每日新闻影响
每天 UTC+8 10:00 检索近 72 小时 NBA 新闻，针对卡库球员判断当日仍相关的卡价利空或利好，在卡片列表显示提示。
验收：每条提示有方向、新闻链接、新闻事实、归因、置信程度、标注时间与到期时间。正负面事件可并存。没有充分依据时不标注，不捏造涨跌幅，不改变估值。
### P1 自动过期
首次标注后 72 小时停止显示，保留历史记录用于核查。
验收：到期瞬间 API 不返回该提示；已打开页面也自动移除。重复运行与同事件转载不得续期；实质性的新进展可作为新事件。
### P2 可追溯与安全
展示只关联到对应球员；现有账户隔离不变。研究只使用公开球员信息，不向新闻搜索泄露持仓、成本或账户信息。

## Requirements
- FR1 每日 10:00 自动启动，时区 Asia/Makassar (UTC+8)。默认最近几天为滚动 72 小时。
- FR2 优先 NBA、球队官方、可信体育媒体，核验发布时间、球员身份和事实；传闻明确标识，无法核验则跳过。
- FR3 分离事实与卡价推断，记录因果链、限制和置信度；不把相关性当确定价格变化。
- FR4 列表新增“风险提示”字段，显示利空/利好及可展开依据、新闻链接。
- FR5 每个球员、事件唯一；重复导入不修改首次标注和到期时间。新闻发布日期不得在未来或超出窗口。
- FR6 无新闻保持空字段；检索或写入失败须报告，不虚报完成；历史提示独立到期。
- FR7 自动任务依赖本机 Codex 可运行和数据库可用；失败可重试，不承诺停机时执行。

## Key Entities
球员、新闻事件提示（事件键、方向、事实、归因、来源、置信度、发布时间、首次标注时间、到期时间）。

## Success Criteria
所有显示提示均具备有效来源链接和归因；相同事件重复执行不产生重复提示；满 72 小时后不显示；现有估值和账户访问边界不变。

## Assumptions
“列表”指卡库列表；新闻为公共球员情报，同球员不同卡片共享提示。保留过期历史而非删除依据。自动检索由本任务每日唤醒执行。
