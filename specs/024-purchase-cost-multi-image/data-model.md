# 历史资料库数据模型

按owner UUID分区的私有文件资料库，目录0700、文件0600、临时文件原子替换。资料不通过uploads或公开接口返回。

| 实体 | 绑定与用途 | 失效条件 |
| --- | --- | --- |
| history state | 账号摘要、页游标、完整覆盖、订单键、抓取时间 | 账号变化、超过24小时、不完整、分页重复或漂移 |
| order | 已登录本人订单的严格OrderCapture，不保存联系方式 | 不属于当前完整快照 |
| gallery / blobs | 商品URL、原订单主图、最多6图、原图SHA256 | 图组过期、文件缺失/损坏、不匹配当前商品 |
| product | 图片哈希、模型与文字合同、独立字段、原始响应 | 当前图组/文字合同不符；仅可用于召回 |
| pair | 当前目标图/商品图、身份、订单hash、模型、v3合同 | 任何绑定变化或24小时过期 |
| preparation / attempt | 每商品完成/失败、每候选尝试次数 | 商品修订变化；成功准备依赖当前有效图组 |
| CLI results / ledger | 冻结100例结果、前后交易行、实际新增差集 | 不把离线same或needs_confirmation计为成本 |

没有新增财务实体。purchase_order、purchase_unit、推断场域和card_transaction沿用既有服务和原子分配规则；资料同步本身不生成卡片成本。
