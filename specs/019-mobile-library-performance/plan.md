# 实施计划

沿用 React/TypeScript、FastAPI/PostgreSQL；原地最小增量保留用户修改，不创建第二套计划。

1. 保留 Workspace 中 LibraryPage 挂载，active 控制可见性、滚动恢复和后台更新。
2. 追加分页，IntersectionObserver 加手动加载后备；请求代次、同步锁和快照重置避免混页。
3. 会话实例的失效订阅；写请求成功失效，60秒后返回重新获取第一页，后台更新时保留旧列表。退出组件销毁清除会话状态。仅保留当前查询，避免查询缓存无界。
4. opt-in ID 快照固定成员和顺序，数据库排序，只投影当前页；完整快照和汇总保留已有路径。
5. DOM 回归、移动端全套测试和构建、后端相关单测；可用时隔离 PostgreSQL 与浏览器验证，记录限制。
