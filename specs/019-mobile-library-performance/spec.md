# 手机版卡库性能

已授权四项：保留会话卡库及查询、排序、滚动；每批30张接近底部追加，重复请求保护、去重、保留列表重试；会话隔离缓存、60秒过期返回后台更新、写后失效和旧请求保护；默认时间排序数据库有序 ID 分页后仅投影当前页。

默认时间排序采用显式 opt-in 成员快照：固定 ID 和顺序，展示值读取时更新；已有完整快照调用保持不变，估值等排序继续全库投影。账户、查询、排序绑定，删除或转移使快照失效。任何缓存不得跨 MobileApi 实例共享。退出清除并取消请求。图片保留现有按需加载，本轮不新增全局图片缓存，避免无界 Blob 内存。

验收：切栏目/详情返回无需重建；加载失败已有卡片可操作；查询变化旧响应无效；写操作失效；默认首批只投影30张；其他排序及完整快照行为不变。仅隔离数据验证，不部署、不写真实卡库。
