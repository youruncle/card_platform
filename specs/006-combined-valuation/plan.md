# 联合证据估值实施计划（2026-09-26 修订）

技术上下文：Python 3.12、FastAPI、Psycopg、Next.js/TypeScript；沿用账户隔离及不可变快照。设计和历史重算已获用户授权，在当前工作区增量实现，保留其他未提交修改。此计划取代最初的两份估价加权方案。

1. codex_joint_valuation 纯函数恢复历史身份字段与证据正文，记录版本、原文、来源类型和不确定性。
2. codex_joint_context 仅校验当前 API 实际服务目录中的图片哈希；独立来源核验记录载入 data/codex_recovered_sales.json。
3. repository.list_items 读取同账户全部成功历史及原估值已采用成交。所有历史走联合证据规则；缺少绑定/身份时保留原值，不能回退到平均模型报价。
4. 校验当前字段、旧确认身份与历史身份；人工估值优先。来源与目标需匹配产品、年份、卡号、插卡、平行、限编、签字、物料及评级。显式子产品不能互用。恢复成交核验状态、实际金额、日期与汇率后才参与计算。
5. 原已采用成交与新增成交按独立链接去重，冲突不能静默吞掉。调用已有 HierarchicalEstimator；无新增有效证据时保留已发表估值或待复核，不因换数学方法无故改价。
6. 列表/详情/盈亏/汇总共用派生结果；只读脚本导出全量审计和改价清单。界面解释一致、补充、冲突字段、价格区间和来源。
7. 失败回归、隔离 PostgreSQL 测试、独立审查、构建、历史全量重算和实际 UI 验收。原始身份/估值/分析不覆盖，不宣称未经测量的准确率改善。
