## 向量与检索边界

固定模型 `google/siglip-base-patch16-224`，revision `7fd15f0689c79d79e38b1c2e2e2370a7bf2761ed`，权重 SHA256 `2c63cb7d1f2e95ba501893cbb8faeb4ea9a3af295498d35097126228659c2af8`。学习得到的图像/文本向量位于同一 768 维归一化空间；模型、分词器、预处理与库版本纳入指纹。不使用随机/文件哈希/SIFT 冒充语义 embedding。

首批离线编码、精确余弦召回，可按赛季、模态和面别过滤；保存模型和来源哈希、版本标记及可重建缓存。图搜图、图搜文字、文搜图、文搜文字都实际运行；自匹配单列，未测独立 Recall@K，也未证明相邻平行卡准确率。相似分数仅是候选排序。当前只索引已核验图片及其来源文字说明，没有把 70 万条清单文字全部编码成向量。

未给生产 API 加载编码器、未迁移 pgvector；未交付应用内融合相似检索或图像浏览页面。生产保存引用/派生索引不代表已有应用检索入口。编码峰值约 1.5 GB，避免影响现有 4 GB API 主机。
