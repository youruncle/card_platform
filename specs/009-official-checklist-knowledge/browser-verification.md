# 知识库浏览改造验收（2026-10-22）

发布补充：同日已随 0.6.4 发布网页及云端 API，并覆盖安装 iPhone 1.1.13（17）。云端健康、源码、目录入口资源、权限和设备版本/启动均完成验证，读取云端已发布 v21，未同步或发布本地知识库。后续发布证据见 [0.6.4 记录](../../docs/release-v0.6.4.md)；以下本机验证与当时未部署状态保留为历史记录。

本记录只验收用户已批准的 US4–US6、FR22–FR27、T029–T035。网页、手机端及只读 API 已实现并完成本机验证；尚未部署线上、未安装到实体 iPhone。年度资料采集、向量检索和历史缺口继续沿用原任务，不因浏览改造完成而勾选。

## 实际交付

- `/knowledge` 默认展示已发布知识的厂商、赛季、系列目录和分项数量，提供卡牌、图库和知识词典入口；原管理功能保留到 `/knowledge/manage`。
- 系列详情包含说明、卡牌清单、来源及有证据的子系列/平行筛选。卡牌详情展示卡号、球员、版本、限编、RC/签字/物料的已知或未知状态、同作用域版本和实际缺图。
- 两端支持筛选、搜索、服务端分页、保留返回上下文、忽略过期响应，以及图库跳转所属系列。
- 图片按设计参考、实卡扫描、未知侧别及实际配对分别呈现；支持缩放、旋转、正反面切换及两图对照。放大后四角均可滚动到达。
- 仅读取不可变发布快照及其校验通过的附件/媒体；派生 SQLite 索引可删除重建。浏览路由挂入现有 `knowledge_api.router`，继承管理员鉴权。手机端使用 Bearer 获取 Blob 并释放对象 URL。
- 图片访问校验快照引用、路径和原始哈希；浏览器不能直接显示的 JPEG2000 等格式生成显示派生图，原文件和哈希保持不变。缺失返回 404，损坏返回 409。
