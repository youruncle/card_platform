# Feature Specification: DeepSeek 联网研究统一

**Feature Branch**: `codex/deepseek-search-fetch`
**Created**: 2026-10-20
**Status**: In progress
**Input**: 实测 DeepSeek 官方 Search/Fetch，可行后完全替代 Qwen，并重新发布 API、网页和个人 iPhone 客户端。

## User Scenarios & Testing

### User Story 1 - 依据实际网页核验卡片 (Priority: P1)

用户录卡后，系统先取得可追溯的公开搜索结果和页面正文，再分析身份。

**Independent Test**: 以真实卡片身份执行只读目录研究，保留查询、链接、正文捕获、抓取状态和时间；来源不足时保留未知字段。

**Acceptance Scenarios**:
1. 可搜索的卡片只使用实际捕获且符合来源规则的链接，保留视觉与目录核验门槛。
2. 搜索为空或抓取失败时明确记录失败，不编造身份或来源。

### User Story 2 - 成交研究保留证据边界 (Priority: P1)

用户估值时使用统一联网研究，保留卡淘直接取证、核图、版本、评级、日期、成交金额、原币种、运费和实卡去重的既有规则。

**Independent Test**: 对 eBay、卡淘和目录站点执行真实只读搜索；无法确认成交的记录不产生正式价格。

**Acceptance Scenarios**:
1. 在售或内容不足的页面仅作为发现线索，不能作为确认成交。
2. 模型输出未捕获的链接时，剔除该来源及其价格依据。

### User Story 3 - 三端发布保留现有成果 (Priority: P1)

用户获得同一已验证后端支持的网页和手机版本，不丢失现有数据、已发布功能或视觉适配。

**Independent Test**: 检查云端健康和实际配置、公网页面与静态资源，并覆盖安装个人 iPhone、复读版本和启动进程。

**Acceptance Scenarios**:
1. 正常运行路径不再调用 Qwen；视觉仍为 `deepseek-flash` 且显式关闭思考。
2. 自动成本 worker 在发布、重启、回退后均保持开启；现有账本和图片不被整库恢复覆盖。

### Edge Cases

- 超长或重复查询、重复链接、不可信域名、内网地址、带凭据的 URL。
- 401/402/403、429、超时、无效 JSON、空结果、只有摘要、部分页面可用。
- 遗留百炼密钥不得发送给 DeepSeek。
- 手机上已安装更高版本、设备锁定或签名失效，不把构建成功当安装和启动成功。

## Requirements

### Functional Requirements

- **FR-001**: 切换前实测官方搜索和抓取，记录成功与失败样本。
- **FR-002**: 目录核验、卡淘发现、通用成交研究统一使用 DeepSeek 官方联网能力，停止 Qwen 运行调用。
- **FR-003**: 保存实际查询、来源链接、捕获时间、内容与哈希、抓取状态；正文截断须明示。
- **FR-004**: 输出来源只能来自本次实际捕获，未知或冲突字段保持不确定。
- **FR-005**: 搜索和抓取具有有限数量、并发、超时和重试；空证据不调用模型补写。
- **FR-006**: 保留直接站点取证及身份、财务、核图和去重门槛；成交证据不足价格为 null。
- **FR-007**: 本次模型请求显式 `thinking: {type: disabled}`，保留已提交视觉适配。
- **FR-008**: 只使用匹配端点的服务器凭据，不在日志、前端或规格记录密钥。
- **FR-009**: 发布 API、网页和个人签名 iPhone，验证运行版本、健康、资源及启动，成本 worker 实际为 true。

### Key Entities

- 联网捕获：查询、时间、URL、标题、摘要、正文、内容哈希、截断标记、抓取状态和错误分类。
- 研究结论：既有识别和成交候选关联本次捕获，保持现行入库规则。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 目录、eBay、卡淘三类真实搜索均留存结果，至少一个公开页面抓取成功，失败如实记录。
- **SC-002**: 三个研究入口通过回归，未捕获来源不能接纳。
- **SC-003**: 新增失败场景通过针对性回归，与既有基线差异明确。
- **SC-004**: 公网页面及资源可访问、API 健康；iPhone 版本复读与启动通过，或明确实际阻塞。

## Assumptions

- 用户已授权条件可行后的完整替换和三端发布，例行实现与发布持续推进。
- 完全替代指运行调用；保留兼容类名和历史证据不等于继续调用旧供应商。
- 抓取受站点策略影响，404/504 不允许放宽成交证据要求。
- 不新增数据库迁移，不重跑逐卡估值，不批量改写真实卡库。
