# 手机详情管理验证报告

实现 CardManagement.tsx，复用现有 MobileApi、身份审核、估值、交易、持仓和软删除接口。只改动新增组件、对应组件测试与本报告。

- 估值首次读取成功前禁止发起；运行中禁重复，2500ms轮询，终态停轮询；请求序号屏蔽较旧响应，切卡、换API与卸载隔离后续更新。
- 全部 ConfirmedCardIdentity 字段可人工编辑。候选须用户选择，保留来源与冲突；人工修改逐字段注明 manual 和实际理由，理由至少3字。失败保留表单，读取失败可刷新恢复。
- 交易以 TransactionCreate 字段提交，日期与单价必须确认，汇率、币种、数量及费用可编辑；成功回读后台历史，清除日期及单价防重复保存；没有客户端盈亏计算。
- 持仓 PATCH；单卡删除带 owner_id 和 reason，浏览器确认后移入回收站。身份和交易使用默认折叠详情，减少初始页面长度。

## 实际验证

- `npm test -- --run tests/card-management.test.tsx`：10/10通过，涵盖加载/运行禁重复、终态轮询停止、并发读取顺序、候选来源、人工确认失败保留、初始身份失败恢复、交易成功防重复、持仓与删除成功失败、切卡时迟到响应隔离。
- `npm run build`：TypeScript 与 Vite production build通过。
- 全套 `npm test` 当次：97通过、2失败，分别是 core.test.ts 的 disposed session 错误文案断言及 player-prices.test.tsx 的 monthly market 近30日中位价断言。两处不在本子任务改动范围，已告知主代理跟进。

没有连接真实外部估值服务、真实账户数据或 iPhone 原生设备；本报告不宣称这些路径已验证。浏览器窄屏集成验证由主代理执行。
