# Feature Specification: 全库中英文搜索与高级筛选

**Feature Branch**: 依用户要求在原 main 工作区增量开发，不切换分支
**Created**: 2026-09-21
**Status**: Implemented, independently reviewed, tested and deployed locally
**Input**: 搜索移到核心持仓附近，覆盖所有私有卡片，支持中文译名、模糊匹配及卡牌属性组合筛选。

## User Scenarios & Testing

### User Story 1 - 找到当前页以外的卡片 (Priority: P1)

用户在核心持仓标题下输入 ID、球员、品牌或卡种，查询整个当前账号卡库。
**Why this priority**: 当前页筛选不能满足数百张藏卡的定位需求。
**Independent Test**: 放置 35 张卡，搜索原第二页目标，得到正确总数和目标；清空恢复 35 张及分页。
**Acceptance Scenarios**:
1. 输入 ID 519，只返回 display ID 为 519 的自己的未删除卡。
2. 搜索得到超过 30 张时，分页总数及下一页都使用相同条件。
3. 搜索期间连续改词，旧请求不得覆盖新结果；失败显示重试提示。

### User Story 2 - 中英文及模糊查找 (Priority: P1)

**Why this priority**: 用户习惯中文球员名和俗称，库存常为英文。
**Independent Test**: KEVIN DURANT、凯文杜兰特、杜兰特召回相同球员；部分名称和轻微英文拼写错误有效。
**Acceptance Scenarios**:
1. 大小写、空格、常见标点及英文重音差异不影响姓名查找。
2. 已收录中英文别名双向匹配，关键词可跨球员、年份、系列字段组合。
3. 未知译名不会自动编造映射；ID、年份、卡号和限编数字不做拼写容错。

### User Story 3 - 按属性组合筛选 (Priority: P2)

**Why this priority**: 精确缩小大量卡片范围。
**Independent Test**: 球员+签字+限编范围取交集，单个品牌内多选取并集，删除标签和清空可还原。
**Acceptance Scenarios**:
1. 支持球员、品牌、产品系列、特卡、平行、卡号、年份范围、实编/总限编、RC、签字、物料、评级公司及分数、成本/正式估值范围、成本是否录入和估值状态。
2. 布尔属性提供全部/是/否；未知评级不当作零分；未录入成本不当作零成本。
3. 高级筛选默认收起，有可删除条件标签；手机窄屏不横向溢出。

### Edge Cases

空白关键词、零结果、特殊符号、超长查询、非法/倒置范围、中文输入法组合、过期响应、账号切换、删除卡片、同名多人、缺少属性。

## Requirements

### Functional Requirements

- FR-001 搜索框位于核心持仓标题下、表格上，顶栏旧搜索框移除。
- FR-002 全库过滤在分页之前执行，默认每页 30 条；账号及未删除范围不可绕过。
- FR-003 关键词支持 ID、姓名、品牌、产品、特卡、平行、卡号、年份及限编；词之间取交集。
- FR-004 已发布知识库与已有球员别名可用于双向检索；模糊仅为发现，不修改身份或估值/成本匹配门槛。
- FR-005 高级筛选覆盖 US3 列表，同字段多个值取并集，异字段取交集；组合关键词时也取交集。
- FR-006 展示结果数量、加载/错误/空态、已选条件、一键清空，改变条件回到第一页。
- FR-007 不修改真实卡库身份、账本、估值或用户工作区的无关内容。

### Key Entities

- 搜索条件：关键词、分类多选、三态属性、数字范围。
- 搜索结果：当前账号可见卡片、匹配总数、页码。
- 别名：可追溯的名称同义关系，仅影响检索召回。

## Success Criteria

- SC-001 原第二页目标可由第一页入口查到；跨页计数与结果均正确。
- SC-002 三种杜兰特名字查询在相同条件下返回相同卡片集合。
- SC-003 所有已列筛选属性都有正常、边界或组合验收覆盖。
- SC-004 账号隔离与删除排除测试零泄漏；现有成本和估值测试不退化。
- SC-005 本地现有约 519 张卡库的常用查询实测目标不超过 1 秒，不包含网络故障；报告实测而非推测。

## Assumptions

全局指当前账号全部未删除卡片，不含他人卡片或回收站。范围含端点；年份匹配赛季区间重叠。
成本状态指已有买入成本（包括人工及零成本），不只卡淘来源。金额范围按账户本位币；估值仅正式值，不使用影子价格。
不引入每次输入都调用大模型的在线翻译，别名覆盖不足保留原关键词。不改变资产总览统计口径。
