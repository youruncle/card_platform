# Feature Specification: 登录体验与云端数据更新

**Created**: 2026-10-16
**Status**: 已发布并完成卡库同步验收；共享市场元数据与复核工作台候选限制见validation.md
**Input**: 优化登录提示；手机版仅输入用户名和密码、固定服务器；发布云端和手机版；同步本地最新卡片到云端。

## User Scenarios & Testing

### US1 明确登录结果（P1）
用户只需输入邮箱账户和密码；密码不匹配、临时锁定、网络超时、会话过期有可理解提示。锁定时能看到等待时间，不再把正确密码的锁定失败误认为密码错误。

验收：第五次失败明确显示锁定；锁定期间不重复提交，期限结束可以重试；错误密码和未知账户保持统一失败提示；正确密码建立会话。

### US2 固定服务（P1）
手机版固定连接 https://cardsp.cn，登录表单无服务器输入。已有正确域名会话保留；旧地址的会话安全清除并要求重新登录，不能将旧地址的token转发给新服务。

### US3 云端卡片同步（P1）
用户自己的本地最新收藏及关联交易、估值/分析和图片可在云端手机查看；只同步该账户授权数据及必要共享身份资料，保留云端独有记录和其他账户。先备份、审计、验证再合并，不使用全库覆盖。

### US4 最新版本发布（P1）
云端和已配对开发iPhone都运行本次版本。生产登录、匿名/其他账户隔离、静态资源、图片及数据汇总通过验收；明确真机签名期限及未实测部分。

## Requirements
- FR001 保持密码校验及失败锁定机制，明确区分可重试的锁定状态和密码错误。
- FR002 登录不显示服务地址输入，支持密码显隐、防重复提交及系统自动填充。
- FR003 手机用户继续使用原云端账户；数据同步不迁移密码、会话、第三方账户密钥或本地环境配置。
- FR004 同步前审计目标账户、外键依赖、已有数据冲突、图片可达性并生成备份；不得修改其他账户数据。
- FR005 按同一记录ID合并；云端独有数据保留。本地同ID记录为本次同步主来源；发现云端更新更晚或涉及他人共享记录时保留并报告冲突，避免静默覆盖。历史纠正先更新已被替代的旧记录再插入新记录；同卡同字段真正竞争的未关闭记录按自然唯一键复用云端ID并比较更新时间，保留已关闭历史及较晚人工决定。
- FR006 图片同步校验内容及路径，不让未经授权账户获得访问；重复执行不得重复卡片、交易或图片。
- FR007 本次为一次性同步；不新增自动双向同步或定时任务。
- FR008 当前有效确认身份的账户专属证据接受/拒绝决定按本地最新主来源同步；保护云端较新卡片、更高确认版本、历史版本及已撤销版本。共享市场缓存/证据/可比卡的已有同ID行保留云端内容，其分类和刷新元数据不在此次更新范围。

## Success Criteria
- SC001 登录相关真实数据库回归及手机界面测试通过，云端锁定响应能指导正确重试。
- SC002 发布后手机无需服务器输入即可连接既定域名，老会话处理符合US2。
- SC003 目标账户本地快照内所有可同步卡片及必要关联数据都能在云端读取；图片哈希和业务数量核对通过，缺失或冲突逐项记录。
- SC004 原云端独有记录、其他账户凭证/数据及服务开关得到保留；有可执行回退点。

## Assumptions and Boundaries
用户已授权上述工作持续推进，按项目约定维护同一份spec/plan/tasks，不重复设计审批。当前工作区与`.specify/feature.json`属于其他未提交功能的状态保留，本文显式指定018目录。数据源为用户当前账户本地快照，云端手机读取同一后端。真实凭证和数据包仅保存于受保护运行目录，不写入规格或版本库。
