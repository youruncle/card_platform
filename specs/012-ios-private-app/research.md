# iPhone 私人卡库设计草案

状态：2026-10-05，供讨论；未进行实现、部署、真机或性能验证。

## 已选方向

用户选择 Capacitor。建议新增 apps/mobile，采用 React + TypeScript 的移动端界面，提取适合共享的接口类型、格式化和业务展示逻辑；避免直接把现有巨大桌面页面整体复制。现有 Next.js 桌面入口继续使用。具体构建工具在 plan 阶段确定。

用户进一步确认：沿用之前的腾讯云服务器，本地卡库数据暂不上传，先打通功能。部署程序时不打包本地卡库、交易、图片或知识库内容，不清空云端已有数据。

移动端将页面资源随安装包分发，经 HTTPS 调用 FastAPI；不依赖在手机运行 Next.js 服务端，也不以远程网站套壳作为正式结构。

## 部署与数据流

手机 App / 电脑网页 → HTTPS 入口 → FastAPI 与后台任务 → PostgreSQL、私有照片卷。
后台任务通过服务端凭证调用外部识别、估值服务。现有 Nginx 与 Docker Compose 可增量配置；API 和数据库继续不暴露公网端口。

部署记录为 2 核 4GB，适合作为小规模验证起点，不能据此承诺吞吐。第一版低并发排队，限制图片尺寸、保留可追溯原图、生成缩略图；资源不足时依据实测调节。常规外部模型调用不要求本机 GPU；平板扫描本地 ML 不纳入首版。

服务端是云端卡库唯一写入源；手机保存待上传草稿。本地 Mac 数据不自动变成云端数据。电脑登录同一云端系统才与手机共享卡库。

现有云端配置存在多个 Worker，各自单并发并不代表全系统单并发；需统一预算图像处理和外部模型并发。补数据库、照片、secrets 的异机备份与恢复演练。

## 手机流程

四个入口：卡库（搜索、筛选、概览、详情），录卡（正面、背面、预览与提交），任务（排队、识别、待确认、失败），我的（账户、设备会话与退出）。

拍照或相册 → 原图保留与上传格式转换 → 本地草稿 → 上传 → 服务端任务确认 → 异步识别 → 字段证据与人工校正 → 幂等入库 → 后台估值。

上传前转换 HEIC、处理方向和大小；如为识别生成压缩副本，应记录与原始上传的关系。失败保留草稿；任务确认后无需应用前台常驻。首版不承诺 iOS 杀进程后的持续后台上传，也不以推送作为恢复任务的前提。

## 鉴权建议

网页版保留现有 HttpOnly Cookie。移动端建议通过原生网络层使用可撤销的服务端会话凭证并存放 Keychain，复用既有会话生命周期和撤销逻辑；不把长期凭证写 localStorage。具体请求桥接与 Cookie/Bearer 兼容方式在小范围接入验证后定案，不直接降低现有 CSRF 防护。

所有接口与照片复用账户归属检查。图片不能假设普通 img 请求自动携带移动端凭证，应经受控下载生成受管理本地资源；退出与切号清理私有缓存及草稿访问权。检查原生网络层超时、错误与取消行为。

邀请为单次、有期限，仅创建普通账户；关闭任意邮箱认领既有账户的入口，不沿用首个注册者成为管理员的初始化逻辑对外开放。管理员的邀请管理和卡库读取权限分离。朋友独立卡库方案仍待用户回答。

## Linux 与现有桌面功能

macOS Apple Vision 与硬件 SDK 不在 Linux 运行，沿用可用的云端识别回退并验证方向、裁切差异。NETUM、平板扫描仪与桌面批量流程保留在电脑端，不纳入手机首版。云端模型密钥、知识库内容和市场源可用性均须单独核验。

## 分发与域名

建议 TestFlight 定向邀请本人和朋友。加入 Apple Developer Program，准备签名、隐私披露和审核用测试账户；朋友作为外部测试者，首次构建需测试审核。每个构建最长 90 天，到期前发布替换构建。这是持续内测方案，不是一次安装永久可用的分发方式。

公网使用需从目前 HTTP 测试入口升级 HTTPS，网页版启用 Secure Cookie。服务器地域和域名状态尚未确认；大陆部署的备案适用性按腾讯云官方指引核对，不能凭少量使用者推断豁免。

## 待定与验证

- 服务器选择已确认，实际资源和入口状态仍待只读核验；独立卡库继续作为建议，未视为用户明确确认。
- 数据范围已确认：当前不迁移本地卡库；程序发布也不携带本地知识库内容。
- 实现前核验 Apple 开发者账号可用性，选择最低 iOS 支持版本。
- 完成鉴权与私有图片、HEIC 上传、任务恢复的小范围接入验证，再展开全部页面。
- 本轮不产生工期承诺；账号共享方式、域名和云端可达性确定后，在同一功能目录生成实施计划与任务。

## 第一阶段联通顺序

1. 核验已有云端服务及 HTTPS 接入条件，保留现有账户、数据和关闭公开注册的设置。
2. 建立移动端基础导航，打通登录、会话恢复、空卡库及退出。
3. 以隔离测试账户和合成图片打通上传、后台任务、状态恢复、人工确认入库、详情和受保护图片。
4. 模型服务可用后，使用专门提供的测试照片验证真实识别和估值；缺密钥、样本或数据源时逐项记录未验证状态。
5. 通过后再补邀请、TestFlight 分发和完整首版验收。

合成样本用于协议、错误与状态流转验证，不替代真实卡片识别回归。测试写入限于专用测试账户；不得把生产账户清空作为测试准备。
