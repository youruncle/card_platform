# Feature Specification: 云端网页使用本机 Canon 扫描

**Created**: 2026-10-20
**Status**: 实施中；用户已确认“继续在 cardsp.cn 扫描，卡片保存到云端”
**Input**: 网页 Canon 扫描因云服务器尝试执行 Mac 程序报错，需接通真实本机取图与云端卡库。

## User Scenarios & Testing

### User Story 1 — 云端网页扫描 (P1)

用户在接有 Canon LiDE 400 的 Mac 上登录 cardsp.cn，连接本机扫描助手，扫描正面及背面，继续现有云端裁切、校正、配对、确认录入。相同卡片不写入本机卡库。

1. Given 本机助手运行且扫描仪连接，When 连接扫描仪，Then 展示就绪并允许 300/600 DPI 扫描和概览。
2. Given 真实取图成功，When 返回原图，Then 网页通过当前云登录会话上传到当前云扫描批次，保留真实分辨率和预览标记。
3. Given 两面完成，When 配对并确认，Then 沿用现有身份门禁、图像归属、幂等确认与云端识别队列。

### User Story 2 — 连接与上传失败可恢复 (P1)

1. 助手未运行、网络权限拒绝或设备未连接时展示可操作提示及重连按钮；已有整版图片仍可上传。
2. 设备忙碌时拒绝第二次取图，不并发启动两个扫描进程。
3. 扫描成功但云上传失败时，当前页面保留原图，提供重试上传和下载；重试不重新启动扫描。重试完成前不允许覆盖待上传图。

### Edge Cases

连接期间按钮禁用；超时、取消和浏览器断开需释放扫描仪；助手重启后旧令牌失效并允许重连。输出路径由助手生成且不得由请求指定；其他站点、非回环 Host、无来源与无令牌请求不能取图。预览实际 DPI 与用户选择 DPI 分开记录。

## Requirements

- **FR-001**: 本机仅负责探测及取图，云端负责原图存储、裁切、配对、身份审查和识别入库。
- **FR-002**: 本机助手只监听回环地址，只接受 cardsp.cn 和本机开发网页的明确来源；浏览器获得的短期进程令牌仅保存在内存。
- **FR-003**: 云登录 Cookie、模型密钥和账户数据不发送到本机助手；本机接口不接受任意文件路径、命令、上传目标或云凭据。
- **FR-004**: 扫描图以原始字节传给网页，再经当前用户认证上传到原有云端批次；原图的真实像素尺寸与 DPI 分开验证。
- **FR-005**: 设备探测、概览和扫描互斥；明确区分设备忙、缺失、超时、上传失败。
- **FR-006**: 保留已有同机 API 扫描与整版图片导入，不改变正背配对和估值规则。
- **FR-007**: 本机助手开机自动启动；网页提供连接/重连入口及浏览器本机网络权限说明。
- **FR-008**: 发布仅叠加相关源码到当前线上版本；保留 deepseek-flash 及 thinking disabled、独立搜索配置与 PURCHASE_COST_WORKER_ENABLED=true。

### Key Entities

扫描连接（设备能力、短期令牌）、待上传原图（面、字节、DPI/像素元数据）、现有云扫描会话。无新增云端数据表。

## Success Criteria

- **SC-001**: 当前 Mac 上通过 cardsp.cn 完成至少一次真实 Canon 取图并在云扫描批次中显示该原图/区域；不再调用云端原生 capture。
- **SC-002**: 自动测试证明上传重试不重复扫描，故障分支仍可导入文件，其他来源及错误令牌无法驱动设备。
- **SC-003**: 相关 API 测试、全部网页单测、类型检查与生产构建通过；明确报告未验证的背面实物翻转和自动入库。
- **SC-004**: 发布后健康、实际 worker 设置和模型隔离验证通过，现有云卡库记录不因验证被新增或改写。

## Assumptions

用户已确认云端保存。当前范围为这台接有 Canon 的 Mac 与网页；手机端无 Canon USB 功能或界面变更。验证可保存扫描批次原图，但不确认新增实物卡入库。浏览器首次访问本机可能需要用户授权本地网络。
