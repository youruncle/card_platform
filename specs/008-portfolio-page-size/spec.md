# 卡库浏览、排序与相关度检索

## 用户场景与验收
用户查看卡库时默认每页 30 张，可选择 10、20、30、50、100 张。
改变数量后返回第一页，保留搜索筛选条件，清除已选卡片。
翻页、搜索及后台刷新沿用当前数量；重新打开页面恢复默认 30。
请求失败显示错误并支持重试；旧请求不得覆盖新数量的结果。

## 功能要求
- 在表格上方操作栏提供有明确标签、键盘可操作的数量选择器。
- 正确显示总数、当前页和总页数，最后一页允许不足选定数量。
- 接口默认 30，允许 1–100，拒绝越界数量；账户隔离不变。
- 保留已有未提交修改，不更改卡库数据。

## 成功标准
五个数量选项请求和显示一致；筛选、翻页、后台刷新保持选定数量。
移动窄屏分页栏可用；超出范围的页码由服务端收敛至末页。

## 假设与边界
不增加任意数量输入或跨会话保存偏好；只调整现有卡库分页。

## 2026-10-07 增补验收
- 排序与每页数量放在表格上方；增加未实现盈亏金额排序，使用页面最终投影值，负数、零、正数正确排序，未知值和已售卡片排在末尾。
- 关键词改为相关度检索：分词、别名、部分名称及轻微英文拼写错误可召回；不要求全部词命中。命中更多条件、完整名称的结果优先；完全无关结果不召回。纯数字及 ID 查询仍精确匹配。
- 新关键词默认切换为相关度降序；用户可再选盈亏等字段排序。高级筛选仍是硬条件。分页与快照保留排序、筛选和账户隔离。
- 减少首次列表加载中重复执行的全库投影；总览统计保持整个账户范围，不因关键词或高级筛选缩水。延续快照时复用同批统计。
- 用现有真实 618 张卡片只读测量优化前后耗时和结果摘要，验证估值、成本、身份字段不变；不更改真实卡库数据。
