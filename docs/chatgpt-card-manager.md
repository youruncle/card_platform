# ChatGPT 卡牌管家

远程地址为 `https://cardsp.cn/mcp`。开发与真实验收进度见[任务清单](../specs/028-chatgpt-card-manager/tasks.md)和[验收记录](../specs/028-chatgpt-card-manager/verification.md)。开发清单不等于用户卡库的后台任务。

## 私人连接

在已登录 ChatGPT 的 Plugins 页选择加号 → 添加自定义 MCP 服务器，填写名称“卡牌管家”、上述地址，选择 OAuth。读取服务器发现结果并选择动态客户端注册（DCR）；回调必须与平台部署允许的精确 URI 一致。通过现有卡牌平台账户登录，在授权页核对权限。密码只在原平台输入，不发到聊天。

2026-10-28已在实际账号完成私人MCP连接。Skill的实测安装路径为“技能 → 添加技能 → 从电脑上传”，选择只包含 `skills/card-manager` 目录三份文件的技能ZIP，核对“已安装”列表出现“卡牌管家”。在“在聊天中试用”时，将自动填入的“编写示例”提示替换为实际请求，防止改写示例时遗漏筛选条件。

账号另支持完整插件ZIP时，可尝试上传 `plugins/card-manager` 的便携包导入技能及远程配置；该一体导入路径尚未实测。当前已验证的形态是私人MCP与独立安装Skill。手机端可用性以验收记录为准。无需安装 Chrome 商店扩展。商店“item not available”不代表远程 MCP 失败。

连接后先问“核对我的卡牌平台账户和当前可用功能”，检查 profile 和 capabilities。iPhone 当前提供的 ChatGPT 版本为1.2026.153，Build27158052172，实际操作尚待验收；不因版本号猜测支持程度。Android尚待确认。

## 常用操作

- “查我的库里签字且限编的卡，显示实卡编号和图片。”同款多张先核对流水与评级。
- 上传照片后说“第一张正面和第二张背面属于同一张，第三张独立，先识别草稿。”必要身份不明时先校正，识别结束不等于入库。
- “把编号……的备注改为……。”只修改提供的字段；身份校正通过原审核链保存版本。
- “编号……在2026-10-28北京时间20点卖出1张，单价150 CNY，我承担费用10 CNY。”外币补汇率及凭据说明；独立费用另列。
- “把编号……移入回收站”或“恢复原卡”。软删除保留账本，不提供永久删除。
- “为编号……发起本次成交研究。”服务端尝试eBay已售与卡淘历史检索，保存响应和真实失败诊断。研究页补候选链接并启动后台原文/实卡图取证，逐项核图审核后再准备发布。
- “恢复最近的三卡任务，只重试可恢复的失败项。”聊天关闭后用近期任务编号找回；成功和待审核项不重跑，单任务最多三次重试。
- “查看上海时区2026年10月买卖、费用和已实现盈亏。”区间为10月1日00点至11月1日00点，末端不包含。原币金额分列，缺可靠汇率时折算合计为未知。

## 具体确认与撤销

入库、修改、记账、回收站和估值发布均先显示具体影响及平台确认链接。用户在原平台核对批准后，返回ChatGPT执行并回读。口头确认或模型传入布尔值不能代替平台批准。超时重试保留原操作编号，避免重复记账；版本冲突需重新读取、准备和批准。

在 [ChatGPT连接管理](https://cardsp.cn/chatgpt/connections) 查看和撤销本人连接。撤销使该连接的工具和私有图访问失效，保留已经保存的卡片、交易及研究；恢复访问需要重新授权。

## 成交证据与失败恢复

历史估值不是本次搜索。研究保留来源日期、查询、原文与实卡图；403、超时、未绑定查询与真实空列表分开。未知Best Offer金额、挂牌、整包、错版、错评级、品相不符和重复实卡不进入同款成交。至少三条近期独立卖家同款公开成交才给观察区间；不足价格null，不用采购成本或经验补价。公开落槌不代表付款。人工审核和结构校验不证明描述为真，仍需实际查看捕获。

附件过期重新选照片；权限失效重新连接；共享身份更改可能影响其他实卡时，在原平台先解决版本冲突；失败不可恢复或超过重试上限时，检查来源/照片后再决定是否建立新任务。不要反复换请求编号强行执行。

## 发布检查

发布保留成本worker开启、deepseek-flash视觉显式thinking disabled、独立百炼qwen-plus搜索配置。`scripts/verify-chatgpt-manager.py --base-url https://cardsp.cn`验证公网路由；在API容器中加`--runtime`验证实际设置，仅输出布尔断言。确切回调为空时OAuth检查应失败，不能以宽泛通配符绕过。
