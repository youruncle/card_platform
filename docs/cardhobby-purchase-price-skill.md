# 卡淘买入价 Skill

查询本人在卡淘买过的商品金额、分摊运费和订单证据。采用“同账号独立Skill＋卡牌管家云端MCP”，手机与电脑共用云端服务，无需电脑常开或Chrome扩展。关键词入口不要求卡片已经入库；这不是市场估值或竞价建议。

## 使用

在新聊天中同时选择“卡牌管家”插件（可用`@卡牌管家`）和“卡淘买入价”技能，或明确输入“请用卡牌管家的卡淘买入价技能”：

- “用卡淘买入价，按关键词‘库里 国宝’查我买过的卡，列出每笔金额、运费、日期和商品链接。”
- “查关键词‘科比 MVP’，只查价不入账。”
- “查卡库编号859的卡淘买入价，先核对实卡，再显示订单证据。”
- “恢复我上次卡淘买入价查询，继续看下一页。”

关键词最多三组，每组120字符。保留用户提供的条件；多个同款分别列出，不自动选最低/最新一笔。只有照片时先提取可确认关键词，不为了查价先创建持仓。包价和单卡价、商品金额和运费明确分开，缺实付或核图证据保持未知。

## 安装

前提：同一ChatGPT账号已连接“卡牌管家”（`https://cardsp.cn/mcp`），原平台已保存本人卡淘账号。凭据只在原平台输入。

本账号已通过“技能→添加技能→从电脑上传”安装独立技能ZIP，已安装列表显示“卡淘买入价”。其他账号需先连接自己的卡牌管家，再上传只含SKILL.md与agents/openai.yaml的同一技能ZIP。若连接列表仍是旧工具，在插件管理的“刷新工具”重新发现；需要以下三项能力：

| 工具 | 用途 |
| --- | --- |
| start_purchase_cost_lookup | 按keywords直接搜索，或按item_id/revision核图查询，返回任务编号 |
| get_purchase_cost_lookup | 获取任务状态及分页价格候选 |
| list_purchase_cost_lookups | 其他聊天恢复本人近期查价任务 |

手机使用同一账号查看技能入口；实际iPhone/Android可见性、版本支持以[验收记录](../specs/029-cardhobby-purchase-skill/verification.md)为准，网页安装不代表三端已实测。

2026-10-29用户已反馈iPhone关键词查询“查到了”，电脑及iPhone查询路径均有实测记录；Android尚未验收。

真实安装入口：[卡淘买入价](https://chatgpt.com/skills?skill_id=6ae2312d9564819181434bced7999c33)。2026-10-29实际网页验收：中文和英文关键词均返回本人购买记录，商品金额、运费、合计、日期与生产任务一致；旧任务编号可继续回读，关键词召回仍未证明与库存某张实卡一一对应。私人订单明细仅保留在授权聊天和私有验证材料中。

首次试用只选择Skill时，会话曾缺少新查价工具；在插件管理刷新工具后，新聊天显式选择“卡牌管家”已成功调用。遇到同类情况先核对当前聊天是否启用了插件，再开新聊天重试；不要因为服务端get_capabilities列出工具就编造工具已执行。

## 查询边界

查询只保存任务、订单证据和核图缓存，返回ledger_modified=false，不写成本或新增买入账。若要写回，在原平台核对对应订单后确认，不按查询结果另记一次重复买入。原平台既有自动成本worker保持开启，与本次只查价独立。

搜索有页数/订单上限，complete=false不能声称全部查完；返回next_page时继续读取结果页。网络错误不能解释成没买过，登录/短信验证要求在原平台处理，不在聊天中交密码/验证码。超时先用原编号恢复；只有明确换查询或重新查时建立新任务。
