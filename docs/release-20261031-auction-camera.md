# 网页 USB 相机自动取景与手动缩放发布（2026-10-31）

电脑网页的单卡拍卖草稿增加取景预览、自动调整、镜头实际倍率、预设倍率、±0.1×与目标倍率滑杆。当前Redmi专用组件范围1–3×，自动取景最高1.8×，以完整卡片及边距为目标；卡片偏心时提示移动手机，不伪称电脑能改变物理朝向。取景与对焦不会自动生成照片，用户点击快门才拍一张。

## 实现与真实设备

- 采用个人本地开发签名的CardSP USB相机1.0.3（4），只申请CAMERA；不申请INTERNET、麦克风、存储，不写系统相册。用户已明确允许安装与相机权限，并在MIUI本机提示确认安装。后续同证书覆盖更新成功、权限保留。
- 组件入口DUMP保护；ADB临时转发到private abstract LocalServerSocket，随机连接密钥只经Activity intent交付。请求/响应HMAC-SHA256与nonce，socket不传密钥明文；取消/超时按本设备及端点清理端口。
- 直接读取Camera2实际倍率，匹配新倍率帧后回传取景；AF锁定帧timestamp先提交再完成future，预览timestamp必须不早于该锁定帧。每次用户快门在同一认证会话里重新检查取景、锁定卡片对焦，再发出一次JPEG请求；新JPEG按sensor timestamp匹配，避免失焦或误用旧图。
- 原始相机预览在本机做文档/矩形检测，高置信文档优先，包围卡片的支架和内部嵌套图案不当成第二张卡；对焦后再次核对完整边距与目标一致性。图片不发送云端视觉模型。
- 真实Redmi回读1.6000000×与1.4991364×，自动约1.3995157×、verified=true、focus_confirmed=true；确认focus/preview timestamp相同。最终JPEG4208×3120、2,098,014字节，AF状态4，sensor timestamp更晚；sha256 `085cdf8ef3b0c02f38b18c9ab41049852e86482b3ac761a1de3ea403bf6ff280`。验收照片仅存本任务私有目录，未附加到真实卡库/草稿。

## 云端与本机发布

- 实现提交 `c0fb84a82d697cbd634b2b338efdb7c650af7e98`。
- 网页基于当前在线Atlas冻结源逐文件校验111个文件，只叠加5个网页文件；保留图谱、MCP、发现、v1及uploads代理。发布镜像 `card-platform-web:0.6.8-20261031-auctionzoom1`，151个产物逐一SHA验证。
- 只更新网页镜像与本机LaunchAgent；API容器ID、环境、挂载和用户均未改变。用户本次明确要求网页USB控制，iPhone功能无改动，沿用已安装版本。

- 本机助手重启后已识别Redmi，返回camera_controls=true，白名单来源与PNA预检通过。网页实际登录会话已打开单卡拍卖、连接Redmi、返回当前取景，自动调整显示实际1.4×；点击“放大0.1倍”后显示手机实际1.5×及相机回读成功提示，手动控件恢复可用。验证未改卡片身份、价格和持仓，也未上传照片或调用卡淘写入。

## 验证及限制

- 本机协议、Java策略、原生编译/CV实样、HTTP及取消等37项通过。
- 最新在线Atlas基线的网页245项通过；生产构建、TS与静态资源同步通过。已有CSS start兼容性警告保留，未做无关样式改动。
- 锁屏、断连等异常主要有自动测试覆盖，未逐一实机破坏性测试；其他手机未实测。自动检测不是卡片身份识别，反光或多张卡仍需检查取景。卡淘远端草稿接口尚未接入；仍只保存本站平台草稿，没有真实拍卖发布路径。
