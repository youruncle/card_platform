# 卡淘估值失败系统审计与修复摘要

审计数据库：`card_platform`（`127.0.0.1:5432`）
审计时间：2026-09-07（Asia/Shanghai）

## 结论

本次修复不是 Donruss 或单卡特例，而是将所有品牌/产品的卡淘身份判定改为同一套三态合同：

- `MATCH`：标题能确认目标产品。
- `UNKNOWN`：标题没写品牌/产品，或该词可能是 set/insert/parallel；作为 T2 低置信可比成交继续估值。
- `EXPLICIT_CONFLICT`：标题明确写了另一产品、赛季、平行、卡种、限编、球员、评级或多卡 lot；才会剔除。

最终复核当前 85 张未估值卡后，“仅因品牌/产品省略或未知而被误拒”剩余 **0 张**。

## 架构层修复

- 新增共享产品身份层，统一 provider 召回、卡淘入库和估值端的别名、父子产品边界与三态判定。
- 产品词与 set/insert/parallel 角色感知：`Prizm`、`Mosaic/马赛克`同时也是目标平行时，裸词只降为 `UNKNOWN`；`Panini Prizm Basketball` 这类完整异产品仍硬拒。
- 修正中文标题分词/噪声：`2021编年史` 不再被读成 `/2021`；库存路径 `/7075cea/46`、`#WGY2#`、“大比例”等不再误当限编/卡号/命名变体。
- 查询从精确到宽搜分层，12 次有界预算中保留最多 2 条经审核知识别名，且保留主产品宽搜。
- 可比成交统一分级为 T0/T1/T2/rejected。未识别字段进 T2；明确异球员/产品/平行/卡种/限编/签字/球衣/评级仍为最终硬否决。
- 稀疏卡淘成交可直接形成可编辑正式估值：1 条、2 条和 3+ 条分别使用宽区间与置信度上限，不再因“不够 T0”隐藏卡片。
- 模型分析只作为卡淘不足时的补充；只有可访问、有成交类型/日期/币种的引用可进入正式 fallback，在售价或无日期推测不得冒充成交。
- 强制刷新、缓存重分类、不可变快照、精确失效、任务中断回填和查询/拒绝理由均已落库。批次结束时估值和刷新活跃任务均为 0。
