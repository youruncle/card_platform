# 卡淘成交估值 Skill

独立skill：`cardhobby-market-valuation`，显示名“卡淘成交估值”。通过同一账户卡牌管家的云端MCP完成公开历史记录检索、实际商品核图、候选审核及证据统计，不依赖电脑常开，也不要求先入库。

云端安装入口：[卡淘成交估值](https://chatgpt.com/skills?skill_id=6ae60c10f9bc8191937757ad77852802)。使用时在新聊天选择该skill及“卡牌管家”插件；上传卡片正背图并说“查询这张卡的卡淘历史成交，核对同款后估值”。仅关键词也能查，但无目标图时估值保持未知。既有“卡淘买入价”只查本人订单，保持独立。

## 工具

| 名称 | 用途 |
| --- | --- |
| start_cardhobby_valuation | 建立不可变目标、保存附件图证；UUID幂等 |
| search_cardhobby_sales | 按关键词读取已售记录一页，保存实际请求/响应 |
| inspect_cardhobby_candidate | 捕获同商品详情和实际内联卡图；图序不代表正背 |
| review_cardhobby_candidates | 保存逐候选模型判断，校验当前图证摘要 |
| get_cardhobby_valuation | 恢复、分页和报告；capture_ref回读原证据 |
| list_cardhobby_valuations | 跨聊天恢复本人近期研究 |

当前聊天未发现工具时，在插件设置中刷新卡牌管家工具后开新聊天重试。get_capabilities列出工具不代表当前聊天已经能调用，不应编造结果。

## 边界

每任务12页请求、每页60条；失败占预算。成功的相同查询页再次调用返回原捕获，新一轮实时研究需要新run。源站可能限流或改变内部接口，失败不能解释为市场无成交。

目标图片由对话模型识别，候选卡图由inspect返回并供模型比对；模型判断与服务器可验证的价、日期、状态、哈希分列。没有独立云端视觉worker；若客户端无法传递目标附件，仍能查记录但不能形成估值。

只有公开结束拍卖、正出价、价格/日期/出价次数与详情一致的可比同款参与观察。编号卡须读出完整流水以去重。至少三个近期独立卖家、完整目标身份/图证、全部当前候选审核才生成参考区间；样本或图证不足为null。区间为观察最小/最大值，中位数按卖家等权，不含运费，不是统计置信区间。

这是卡淘来源参考，不是本人买入成本或确认付款流水。默认不写成本、持仓、交易或正式估值。进入既有正式估值仍须执行双市场真实检索合同。知识库不因查询或模型别名而自动更新。
