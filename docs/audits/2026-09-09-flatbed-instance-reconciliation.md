# Flatbed：完整实例优先于扫描容量网格

## 复现与根因

- 用户截图：`截屏2026-09-09 02.12.02.png`。
- 会话：`907e7361-5c66-4f56-a048-71e0a8c38e5b`。
- 原始正面 sheet：`087c972f-20b5-4bde-a2f1-c258d703ac9d`，revision 1。
- 原图：2480 × 3507，SHA256 `da52ba9ebe239c5aa68468d428a94ae738dec46550482adc0c5941c3031dd912`。
- 实际是五张卡：上方两行各两张，下方一张居中且不贴行缝。v16 输出六框。

原图的 Canny、灰度连通域、饱和度、固定/自适应阈值已经找到下方完整卡。错误发生在路线仲裁：4×2 是扫描台容量，但 `full_bed_grid` 成功后会丢弃独立实例候选；局部恢复又被限制在每个容量行内，导致同一完整卡被 y=2630 的虚拟行缝分成两部分。第 4 张同样被容量线截断、混入邻卡边缘。

SAM2 是 box-prompted 精修，并不重新确定卡片数量。旧六框中只有三框精修成功，另三框沿用错误框。单框像素存在度无法证明卡片完整：旧第 5 框的 usability 为 1.0，虽然只覆盖半张卡。

## 通用修复（v17）

1. 在容量网格候选和独立实例之间加入整版仲裁。至少两类当前像素路线通过双向 IoU 一致性支持，按路线共识选择实际观测框；不使用卡名、固定卡数或截图坐标。
2. 完整实例可以替换被网格截断的单框，或解释同一物理卡的多个网格碎片。格子只分配给唯一最佳实例，不能吞掉更符合邻卡的区域。
3. 保护已完整的裁图：如果原格已覆盖实例且并非明显过大，不用较小内框替换完整白背/卡套框。
4. 替换集合整体校验，与未替换区域的重叠阈值对齐后续布局层，防止后置去重静默丢卡；评级标签关联和既有空槽保护保持有效。
5. 完整实例框不再重复加 3% 源图 padding，避免再次引入邻卡；仍保留输出白边。
6. 独立新增跨裁图边界内容连续性检查：沿实际四边形边界内外五条采样带检查深色/彩色印刷内容。旧第 3～6 框均能暴露风险；透明灰色卡套边不当作印刷内容。该检查仅显示可编辑的边界提示，不删除或阻塞卡片。
7. 替换网格前做剩余像素检查：遮去已获得独立支持的实例后，原格若仍有分布式卡体内容，禁止吞并。覆盖了实例只侵入邻格约 8%、以及跨行连通块误吞邻卡两个反例。

## 沿整条流程发现并修复的问题

- **SAM2 同步结果被旧框否决**：旧实现用单个精修框与其他卡精修前的粗框比较。两张同时正确移动且互不重叠，也会被误拒绝。改为整组最终候选校验，发生真实冲突才回退相关候选，回退后再次检查，避免引入级联冲突；无关卡精修结果保留。增加 NaN/Infinity、异常 JSON、冲突级联回退测试。保留评级标签保护和背面槽位身份映射。
- **通用补边带入邻卡**：不仅完整实例路线，其他轮廓路线的 3% 补边也可能跨入相邻卡。现在用真实 peer polygon 比较补边前后覆盖，新增邻卡像素时取消源图补边，仍加中性输出白边。新增实际透视裁剪、旋转、JPEG 后的颜色污染断言，并记录真正用于裁图的 `source_crop_points`。
- **45° 四角排序退化**：sum/difference 取极值在对角线布局可能反复选中同一个角点，导致透视变换退化。改为绕质心排序、固定起点、四点凸包非退化校验；遍历四点全部排列验证变换可逆。
- **人工校正继承自动失败**：用户提供合法四边形时，不再先跑自动检测或继承其低布局分数；人工布局有独立来源标记，仍做真实像素质量检查。空白手工框仍告警且可编辑，不伪装成正常卡片。
- **旋转卡片质量误判**：旋转会让外接矩形面积接近翻倍。存在度、邻卡重叠、多卡尺寸判定改用真实四边形 mask、面积和对边长度；mask 外像素不参与统计，也不在缩小图像时插入邻卡信号。
- **人工角点契约**：入口在创建 revision 前拒绝重复、共线、凹角、非有限、越界和畸形四点数据，统一返回 422；合法角点集合不因 UI 点序不同而被拒绝。
- **所有路线统一源图边界**：不再只处理新实例路线；最终输出统一约束 bounds 和四角，修复原始轮廓微小越界造成的假错误。严重越界仍保留显式证据并在独立质量模块中判 error、限制质量分，不能通过截到图片内就伪装成完整卡片。
- **重复计算扫描背景**：共享整版背景亮度，避免每张卡的存在度与边界检查重复转换整张高分辨率原图。保持报告一致性测试。一次 2480×3507、5 卡的质量阶段基准约从 0.48 秒降至 0.09–0.10 秒；这是质量阶段，不是整个扫描流程的提速比例。

可观测性：`current_instance_recovery`、`current_instance_replaced_grid_regions`、`current_instance_reference_boxes`，以及每卡路线共识、替换格数和覆盖率。ML 精修数与 fallback 数保持区分。

## 验证方法

- 新增十一个对象级布局回归：横/纵/双轴跨缝、多个 x/y 偏移、低饱和白背、旋转、紧贴双卡、大间隙末卡、弱侵入邻格及跨行误吞。

## 边界

多路线共识不是绝对正确证明。低对比、严重反光、重叠物体、切出扫描范围仍可能需要校正；本轮解决的是网格压过完整实例、碎片误报完整卡这一类问题，不能把有限语料回放表述为任意布局百分之百成功。

后续改进优先级（不通过降低质量标准掩盖）：

1. 混合评级壳的标签与卡体关联：除面积保护外，增加标签空间包络保留证据；防止保持面积却平移掉评级标签。
2. 缺失或不可信 DPI 的历史导入：分开记录采集 DPI 与图像有效尺度；不能根据期望卡数选择最有利 DPI，也不能把图片常见的 72 DPI 显示元数据直接当真实扫描尺度。
3. 稀疏布局中残留的空槽/邻卡碎片：保留检测不确定性，继续用独立主体覆盖与邻卡证据改进，不为对齐正面数量补造背面框。
4. 文件落盘与数据库事务一致性：当前数据库失败可能留下未被引用的 UUID 目录，应以 staging/提交后确认及可审计孤儿回收完善；不能直接递归清理扫描根目录。纯计算移出会话长事务也需用版本校验配套，避免并发覆盖人工修改。
