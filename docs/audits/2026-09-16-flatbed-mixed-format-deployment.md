# 混排卡片裁切：实现与发布验证

## 本轮范围

修复横竖混排、评级壳/磁吸壳尺寸不同、空槽不规则时，被整版网格切开或补出假卡的问题。沿用当前真实扫描 DPI 元数据，不依赖卡名、卡片 ID、用户预先输入张数或样本金标。历史已提交会话只回放、不重写。

## 设计和实现

1. **当前图像完整对象优先**：多路轮廓相互验证得到实体候选；当完整对象能解释网格且剩余区域没有独立卡片结构时，拒绝网格过切。网格仅为布局候选和遗漏检查工具，不具有固定张数的最终决定权。尺寸、方向、非整齐摆放可各不相同。
2. **整体关联与背景辨别**：评级标签关联必须有合理形状，不能把更近的细壳边当标签；残余区域依靠分布式结构、边缘和变化判断，不能把灰底亮度低直接当作有卡。
3. **边缘精修不可破坏完整对象**：SAM 的模型分数不能证明卡片完整。实际多边形交集覆盖不足 95% 时，保留已验证的完整包络，记录回退原因；旧正面槽位或人工框不当作当前背面像素的完整物体真值。
4. **精修后的独立检查**：检测完整对象被拆成多个 crop、一个 crop 混入多个对象、完整对象漏掉、已确认空区生成 crop。错误留在草稿可编辑，不删除原图，不自动提交。源图边缘接触继续给黄色提醒。
5. **回归看实际裁切区域**：除了张数，还按实际裁切多边形检验完整打印区、评级标签、签字区、邻卡污染与空床占用。金标只在评分阶段使用。
6. **正反面服务链路遵守相同优先级**：当检测器明确标记当前完整对象布局可用时，不再无条件按旧正面槽位再次截取背面，也不把旧槽位传作 SAM 的限制框。正面旧框过切、合并或位置冲突分别诊断；张数差异仍如实提示，不能为了匹配数量制造半张卡。
7. **保存可靠性**：将图像计算产生的 NumPy 数值和布尔量规范化为原生 JSON 类型。变形测试发现某些曝光图的质量结果原本可能无法写入 JSONB；新增标准 JSON 序列化回归，不能仅在审计工具中将其转成字符串掩盖生产保存错误。

主要文件：`flatbed_detection.py`、`flatbed_ml.py`、新增 `flatbed_object_quality.py`、`flatbed_service.py`。前端补齐完整性错误的中文说明。

## 已知边界

不能从被遮挡或超出扫描范围的像素恢复真实内容。强反光、壳体粘连、元数据错误等输入仍需明确的不确定性提示与可编辑裁框，不能保证任意图片绝不出错。当前对象优先分支需要多路线相互验证；证据不足时不通过降低残余检查门槛来吞掉淡色卡背。人工确认布局保留优先，不被自动改写。

故障注入把图片缩到 2/3 却仍谎报原 300 DPI 时，仍识别成 4 框；正确传入缩图后 200 DPI 时识别 5 张并通过几何检查。该项作为未来元数据鲁棒性改进点保留，不把故障输入算作本轮通过样本。
