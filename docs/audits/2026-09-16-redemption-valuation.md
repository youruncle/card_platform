# 交换板识别与估值修复

## 问题与修复

截图对应 Khaman Maluach / 2025-26 Topps Inception / RJ-KM。
旧 scanner result 的 caveats 已明确说明 Redemption Card，但估值身份、市场缓存和商品形态匹配没有交换板字段。
识别归一化还因未见实物物料窗而清除了承诺兑换卡的 Relic 属性；MarketIdentity 没有 is_memorabilia 字段，后台检索也会丢失这一属性。

- 识别新增 is_redemption、redemption_status；读取旧识别说明恢复交换板身份，但不从说明里提到 redeemed 一词推断兑换码已使用。
- 交换板的签字／Relic 属性描述承诺兑换的卡，不要求凭证上存在物料窗。
- 估值身份与市场缓存区分交换板形态、兑换状态，传递 is_memorabilia。
- 查询预算优先保留球员＋产品＋交换、球员＋交换及 redemption 查询。
- 普通实体卡与交换板双向隔离；已兑换、空板、已过期凭证不能作为可兑换交换板的直接价格依据。
- 最终成交准入重新检查原始标题；已审核标记不能绕过形态冲突。
- 交换板共用底图的几何相似不作为同卡锚点；视觉模型必须核对印刷球员、卡种、卡号、平行文字。
- 详情页显示交换板及兑换状态。未知状态不会被当成已确认未兑换。
