# Card Platform v0.5.0

发布日期：2026-09-21。

## 主要变化

- 卡淘估值使用身份、原卡正背面、候选图片、标题和来源版本绑定视觉结论；过期或冲突的旧结论必须重新核验，避免退回文字匹配后引用错卡。
- 同款视觉判断分别比较构图与固定表面纹理，保留平行、评级、套卡、交换板、成交状态和品相硬约束。
- 改进身份字段角色、中文实体别名、查询族和有界分页召回；保留未知字段，不用采购成本或猜测价格补估值。
- 增加只读影子评估、模型调用追踪和固定样本回归；生产估值批量写回仍受验收指标约束。
- 候选图片下载、模型批次及本地几何评分并发执行；几何评分只作为审计信息，不改变模型判定或价格。
- 确认新身份后，旧身份估值保留在审计历史中但不再作为当前估值；同时关闭可能覆盖已确认身份的旧纠错建议。
- 包含当前工作树中已完成的卡淘采购成本、组合检索、扫描与批处理界面改进。

## 发布约束

- 本版本部署应用代码，不自动重算或覆盖现有正式估值。
- 估值质量固定样本目前只有1张充分独立价格参考；合理覆盖、总体价格偏差和完整同条件成本验收尚未通过。
- 新估值继续采用保守证据门禁；证据不足保持未知。
