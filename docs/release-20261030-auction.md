## 发布中发现并纠正的问题

初版隔离构建将已部署但未入Git的两条MCP/发现代理规则替换成HEAD配置，导致上线后发现接口404。定位后先仅回退网页到原镜像，保留健康的新版API；确认原接口200及卡牌管家查询恢复。随后从已部署基底保留代理规则，与USB反馈修复一起重建网页auction2。最终候选和运行容器均检查四类代理、全部发布文件SHA与真实公网发现接口，均通过。没有用拍卖上线掩盖现有连接回归。

Mac大小写不敏感导致最初云端暂存包额外包含本地签名App构建副本。Docker上下文白名单没有把它放入镜像或公开目录；随后使用独立 `cloud-payload` 重打纯云端包，并移除私有暂存目录的重复App副本。最终云端包只含API、网页、0091迁移与清单。
