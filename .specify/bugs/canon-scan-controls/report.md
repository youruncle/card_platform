# Canon 扫描入口与批次操作简化（2026-10-30）

用户反馈：每次进入扫描面板都要手动连接，“开始下一批”按钮增加无效操作。截图为用户提供的 `截屏2026-10-30 09.57.47.png`。

## 根因与修复

- 云端网页初始化仅设置“请连接”提示，探测本机助手只绑定点击事件；连接函数还被初始 `busy=true` 阻塞。改为面板打开后自动探测，初始化会话与连接设备并行进行，只有失败时显示重试入口。连接结果检查取消信号和当前请求身份，关闭面板后不会回写过期结果。
- 手动批次入口原本负责创建独立会话，但提交成功并未重置当前面板。移除该按钮；提交成功后清空本批裁图、配对，下一次扫描或导入正面时以 `new_batch=true` 创建独立会话。录入前重扫继续使用原会话。
- 扫描和上传显式使用本次操作对应的会话 ID，避免新建会话后闭包仍指向已提交的旧批次。云端上传失败保留本机图片，重试沿用新会话并且不重新扫描；创建会话失败则不启动采集或上传。
- 保留首次浏览器本机网络授权、来源限制、令牌与云端凭证隔离。采集失败后连接入口可恢复；上传失败不清除已经有效的设备连接。
