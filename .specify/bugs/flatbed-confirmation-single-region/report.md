# 可见参考图确认录入、单张校正与保存反馈（2026-10-31）

## 用户要求与根因

用户截图 `截屏2026-10-31 01.04.15.png` 显示“配对缺少裁图，请先校正布局”。前一次修复使图片接口可以返回参考预览，但 `pair_source_snapshot` 仍在显式配对确认时拒绝 NULL 裁图路径，因此图片可见但不能录入。

原校正入口一次提交整版所有框，服务重建全部裁图并清除配对。保存错误只显示在弹窗后方的全局状态中，按钮没有保存中文案；原图被限制高度、SVG 却覆盖整个容器，也会使拖动框与原图比例不一致。此外，布局保存成功、随后配对生成失败时，界面关闭编辑器并保留旧区域编号，没有可用重试入口。

## 修复

- 在用户明确确认当前配对时，才物化缺失的参考裁图。使用与当前预览一致的原图包围矩形及记录方向，校验原图哈希，记录来源与生成方式；保留原裁切警告和低置信度。图片 GET 保持只读，身份冲突和审核门禁保持原行为。
- 现有布局 API 接受可选 `region_id` 和一个四角框，验证区域属于当前源及账户；生成新版本，仅重建该区域，其他区域复用原裁图路径、边界、信号与置信度。发布前在会话锁内再次检查源版本，拒绝晚到的旧请求。
- 用户人工指定的四角框不再因为同一自动边界警告被取消输出，警告仍保存。原图及历史区域保持不可变。
- 配对卡新增“校正正面 N / 校正背面 N”入口，弹窗只编辑该张的框；保存中禁用重复提交，错误在弹窗内显示并可重试。原图与 SVG 同比例显示，保存栏保持可见。
- 布局保存后立即把旧区域编号映射到新版本，保留用户其他配对选择。候选配对更新失败时禁用录入、显示重试入口；重试保留选择，防止提交旧编号。
