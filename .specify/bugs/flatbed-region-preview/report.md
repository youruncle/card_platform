# 扫描配对页面缺图（2026-10-31）

## 症状和根因

用户截图 `截屏2026-10-31 00.40.57.png` 中卡片 6 的背面破图。云端会话 `50f3adab-83d5-4073-9ed1-b4b6c027da0d` 的背面版本中，第 4、6 张均因 `card_outline_unresolved` / `original_content_missing` 没有生成可录入裁图，数据库 `crop_path` 为 NULL。整版原图仍存在。

`GET /v1/flatbed/regions/{region_id}/image` 将 NULL 传入路径拼接，抛出 `TypeError` 并返回 500；非空路径对应文件丢失时，`FileResponse` 同样会报 500。边界审核保留区域供人工编辑是已有行为，缺陷在于展示接口不支持这种合法状态。

## 最小修复

- 图片接口在裁图不存在时，从原图中的区域包围矩形生成仅供人工核对的 JPEG 参考预览，沿用已记录的方向。使用包围矩形保留待确认的边缘，不对被否决的四角进行透视裁切。
- 预览通过 `X-Flatbed-Preview: uncorrected-region` 标记，私有且禁止缓存。不写回数据库或磁盘，不修改边界审核结果、配对或录入检查；已有界面的边界警告继续显示。
- 原图不存在、为空、损坏，或路径/区域无效时，返回明确的 404，避免 500。正常裁图原样返回。
- 保留区域和整版的账户所有权检查以及私有目录边界。
