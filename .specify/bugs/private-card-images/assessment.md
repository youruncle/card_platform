# 私有卡牌图片缺少鉴权

已在临时 PostgreSQL 和真实上传图片上复现：未登录 GET /uploads/<卡牌图片> 返回 200，应返回 401。根因是 main.py 直接挂载 StaticFiles，不执行 current_user 和账户所有权判断。

修复范围：替换该静态挂载，保留原 URL 和前端原生 img；只允许登录账户读取仍被其未删除卡牌引用的正/背面图片。其他账户、孤立文件、软删除卡牌、旧旋转 URL 返回 404；HEAD、Range、条件请求同样经过鉴权。禁止目录与符号链接，响应 private,no-store 和 Vary: Cookie。

后台识别与估值通过本地路径读取图片，保留现有行为。云端仅部署这两份 API 源码，不重新导出本地数据，不开放公网，不改变注册关闭状态。
