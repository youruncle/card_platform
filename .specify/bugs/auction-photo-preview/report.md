# 拍卖草稿图片无法点击放大（2026-10-31）

用户截图中，已有卡图与USB新照片只有缩略图及选中状态，无法检查细节。

根因：AuctionDraftPanel将整张缩略图放在checkbox的label内，DraftPhoto只有普通img，没有接入主页已挂载的GlobalImageViewer。点击图片只会切换选中状态。

最小修复：照片容器改为div，图片按钮打开现有查看器；单独label保留复选框及说明。查看器使用原始受保护图片URL和完整草稿照片列表，支持已有卡图/上传/手机照片、前后切换、既有缩放及旋转。缩略图继续以带凭据请求的blob加载；查看原图沿用同站点cookie鉴权，不新增公开图片端点。查看器打开时获取焦点并圈定Tab，关闭后恢复缩略图焦点，避免Esc误关底层草稿。

验证：新增回归在旧实现上因缺少图片预览按钮失败；修复后拍卖17项、冻结线上最新flatbed-confirm源的网页249项通过。覆盖放大125%、下一张原图、查看不改勾选、Esc只关查看器、焦点及Tab边界、关闭按钮与复选框独立。生产构建/发布及真实浏览器验收随后补录。

范围仅网页图片浏览，不调用相机、不上传照片、不改身份/价格、不写卡淘。保留其余未提交修改。发布以当前flatbed-confirm线上源及镜像为基线，只叠加两处组件和回归测试；无需API或iPhone功能发布。
